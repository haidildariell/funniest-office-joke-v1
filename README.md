## How it works

`main.py` (pure Python, stdlib only, deterministic) writes the winning one-liner to `/output/entry.txt`:

> The CEO announced unlimited vacation, then installed a leaderboard in the lobby ranking who takes the least time off.

Run it with `python3 main.py`. No external files, no network, no git history reads.
